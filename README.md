# AfterTrade

A trading journal for logging setups, tracking risk, and reviewing performance. Start with the demo or import your trades from CSV or JSON.

## Run locally

With Node.js 22.23.4 or later installed, run these commands in the project folder.

```sh
npm ci
npm run dev
```

Open [localhost:5173](http://localhost:5173). Your journal is stored in this browser. Export a JSON backup from Settings to keep a copy.
